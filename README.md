# Trading Dashboard

This project is a Vite-powered React application that renders a dark-themed trading dashboard with portfolio analytics, performance insights, an interactive equity curve, and a holdings table. It was scaffolded from the official Vite React template and enhanced with Recharts for data visualizations.

## Prerequisites

- [Node.js](https://nodejs.org/) 18 or later (includes `npm`)

## Setup

Install dependencies:

```bash
npm install
```

## Development server

Start the Vite dev server:

```bash
npm run dev
```

The command prints a local URL (typically `http://localhost:5173`). Open it in your browser to view the trading dashboard with live reload support.

## Production build

Create an optimized production build:

```bash
npm run build
```

Preview the built assets locally:

```bash
npm run preview
```

These commands help reviewers verify the dashboard end-to-end.
